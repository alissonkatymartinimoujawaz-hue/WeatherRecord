Sources & méthode

Quatre villes, un indice régional

Varginha, Carmo de Minas, Boa Esperança et Guapé, chacune avec un poids de 25 %. Cet indice n’est pas une moyenne de toutes les surfaces caféières.

VilleLatitudeLongitude

Coordonnées municipales représentatives. Dans MERRA-2, Boa Esperança et Guapé partagent une maille : celle-ci pèse 50 % de l’indice.

Une source par période

ERA5 alimente l’historique des pluies et températures. La fin de série est complétée par ECMWF IFS, explicitement provisoire, puis remplacée quand ERA5 devient disponible. Les données ERA5 récentes peuvent également être révisées.

NASA POWER / MERRA-2 fournit une comparaison mensuelle indépendante. Son dernier mois peut être plus ancien. Les deux sources restent séparées.

Il s’agit de réanalyses et d’analyses sur grille, pas de mesures de stations dans chaque ville. Les Tmin ne permettent pas de confirmer une gelée dans une parcelle.

Normales, cumuls et données absentes

Normales 1991–2020, calculées séparément pour chaque source. La pluie mensuelle est une somme ; les températures mensuelles sont des moyennes journalières. Tmin/Tmax mensuelles sont les moyennes des minima/maxima journaliers.

Les normales quotidiennes utilisent le même jour du calendrier. Le 29 février repose uniquement sur les huit années bissextiles de la référence. Les cumuls de normale additionnent ces normales quotidiennes.

Un mois incomplet n’est pas affiché comme un total mensuel. Les valeurs absentes restent vides. Un cumul s’interrompt dès un jour manquant. Aucune interpolation ni annualisation.

ERA5 : jours civils America/Sao_Paulo. NASA : temps solaire local LST. Cette différence peut affecter les jours de frontière.

Actualisation quotidienne

La collecte et la publication sont programmées tous les jours à 09 h 17 UTC sur GitHub. L’heure réelle peut varier. Ton ordinateur n’a pas besoin de rester allumé.

Les 100 derniers jours ERA5 sont revérifiés pour intégrer les révisions. La date affichée en haut correspond à la dernière collecte réussie. En cas d’échec, le site conserve les dernières données disponibles.

Sur un dépôt public inactif, GitHub peut désactiver la programmation après 60 jours. Les commits quotidiens de données entretiennent normalement son activité.
